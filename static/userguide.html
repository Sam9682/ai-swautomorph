AI-SwAutoMorph User Guide

Overview

AI-SwAutoMorph is a centralized application management platform that provides user authentication and access to multiple AI applications through a unified interface.

Getting Started

1. Web Interface

Access the web interface at http://www.swautomorph.com (or your domain)

  • Registration: Create a new account with username, email, and password
  • Login: Access your dashboard with existing credentials
  • Dashboard: View and access available applications

2. Command Line Interface (CLI)

Use the CLI tool for programmatic access:

# Register a new user
python3 cli.py register --username myuser --email user@example.com

# List available applications
python3 cli.py list-apps

# Add a new application
python3 cli.py add-app --name "My App" --url "http://myapp.swautomorph.com"

# Initialize database
python3 cli.py init-db

3. REST API

Integrate with the platform using REST API endpoints:

POST /register
Register a new user
Body: {"username": "user", "email": "user@example.com", "password": "pass", "first_name": "John", "last_name": "Doe"}
POST /login
Authenticate user
Body: {"username": "user", "password": "pass"}
GET /api/applications
List all applications
Returns: Array of application objects
POST /api/applications
Add new application (requires authentication)
Body: {"name": "App Name", "url": "http://app.swautomorph.com", "description": "Description"}
GET /api/auth/status
Check authentication status
Returns: {"authenticated": true/false}

4. MCP (Model Context Protocol)

Use MCP for AI model integration:

# Start MCP server
python3 mcp_server.py

# Available MCP tools:
# - list_applications: Get all applications
# - add_application: Add new application
# - list_users: Get all users (admin only)

Application Management

Adding Applications

Applications can be added through:

  • Web dashboard form
  • CLI command
  • REST API endpoint
  • MCP protocol

Application URL Format

Applications should follow the pattern: http://[app-name].swautomorph.com

Examples:

  • http://ai-foodflow.swautomorph.com
  • http://ai-haccp.swautomorph.com
  • http://ai-inventory.swautomorph.com

Deployment

Production Deployment

# Run the deployment script
./deploy.sh

Manual Docker Commands

# Build and start
docker-compose up -d

# View logs
docker-compose logs -f

# Stop services
docker-compose down

Security

Important Security Notes:
  • Change the default SECRET_KEY in production
  • Use HTTPS in production environments
  • Regularly backup the database
  • Implement proper firewall rules

Database

The application uses SQLite database with two main tables:

  • users: User accounts and authentication
  • applications: Available applications and their URLs

Troubleshooting

Common Issues

  • Database not found: Run python3 cli.py init-db
  • Permission denied: Check file permissions and Docker access
  • Port conflicts: Ensure ports 80 and 5000 are available
  • Service not starting: Check logs with docker-compose logs

Support

For additional support:

  • Check application logs
  • Verify Docker and Docker Compose installation
  • Ensure proper network connectivity
  • Review environment configuration
